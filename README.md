A program that writes one image summing up the world news of Saturday 21 November 2026: a front-page poster led by the AI-driven global market sell-off, with panels on the missile strike on Kryvyi Rih, the capture of cartel boss 'El Chapo Isidro', the World Court's Myanmar genocide ruling, the COP31 talks running into overtime, the UN pledge to draft 'killer robot' rules by 2028, and bacteria-carrying mosquitoes cutting dengue in Brazil. The poster is composed by compose.py (Pillow) into entry.png; main.py writes it to the output directory, byte for byte.

## Run it

```sh
python3 main.py
```
